# Шрифт проекта

Сюда кладётся **Grunge Bold V2** (`Grunge Bold V2.ttf` или `.otf`).

Как только файл окажется в этой папке, им начнут писать ценники
(`PriceTag`) и баланс звёзд (`StarBalance`) — назначать шрифт в каждом
узле не нужно, его находит `UiFont` (`_Game/UI/Widgets/ui_font.gd`).

Подхватываются имена файла: `Grunge Bold V2.ttf`, `Grunge Bold V2.otf`,
`Grunge_Bold_V2.ttf`, `Grunge_Bold_V2.otf`.

Отдельному узлу можно задать свой шрифт полем «Шрифт» в инспекторе —
оно всегда важнее общего. Пока файла нет, надписи рисуются системным
шрифтом-заглушкой.
